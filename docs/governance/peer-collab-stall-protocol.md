# 동료 세션 협업 — 정체 감지·재개 규약 (Claude ↔ Codex)

> 상태: **제안 + 일부 적용**. §3 은 Claude 가 이미 적용했고, §4·§5 는 Codex 동의가 필요한 양자 조항이다.
> 원장: 이 협업의 유일한 영구 기록은 **GitHub 이슈 #150 댓글**이다. 세션 메시지는 원장이 아니다.
> 발단: 2026-09-11, "Claude 의 도구 호출이 반환되지 않아 협업이 멈췄고 #150 에 상태·재개 조건을 기록했다"는 보고가 있었으나 **#150 에 그 기록이 존재하지 않았다**(§1).

## 1. 조사 결과 — 확인된 사실만

| 주장 | 확인 방법 | 결과 |
|---|---|---|
| #150 에 정체 상태·재개 조건이 기록됨 | `gh api repos/.../issues/150/comments?since=2026-09-10T22:50:00Z` | **미확인.** 22:50 이후 댓글은 Claude 의 리뷰 요청 1건뿐 |
| 레포 어딘가에 기록됨 | 최근 갱신 이슈 12건의 최신 댓글 전수 조회 | **미확인.** 레포 전체 최신 댓글은 22:51:47Z Claude 작성분 |
| Claude 측 도구 호출 정체 | 이 세션의 도구 호출 반환 여부, 배경 모니터 `bzsvte7tv` 상태 | **재현 안 됨.** 모든 호출 반환, 모니터 `running` 정상 |
| Codex 측 회신 지연 | PR #151 마지막 Codex 댓글 `2026-09-10T08:51:22Z`, 이후 리뷰 요청 6건 | **사실.** 약 15시간 무응답 |

조사 후 Codex 가 직접 밝힌 판정 근거(corr `block-prevention-20260911`): **2026-09-10T10:13:04Z 의 Bash 도구 호출 `toolu_01AMvszGGCR11g7je5oDShGe` 의 result 를 관측하지 못한 것**이 유일한 근거였고, 이후 Claude 의 커밋과 리뷰 요청이 확인되어 **세션 실행 불능 판정은 근거가 부족했다**고 스스로 정정했다. 이 정정은 §2 의 진단을 바꾸지 않고 확인해 준다.

결론: **어느 쪽이 멈췄는지 한쪽 기록만으로는 판정할 수 없다.** 그것이 이 문서가 막으려는 결함이다.

## 2. 근본 원인 — 채널에 생존 신호와 신원이 없다

1. **신원 미구분** — 두 에이전트가 같은 GitHub 계정(`holee9`)으로 댓글을 쓴다. 작성자 필드로 Claude 와 Codex 를 구분할 수 없어, 사후에 "누가 무엇을 기록했는가"가 원장에서 복원되지 않는다.
2. **생존 신호 부재** — 침묵하는 동료와 일하는 중인 동료가 구별되지 않는다. 기다리는 쪽은 무한정 기다리거나, 근거 없이 상대가 죽었다고 단정한다.
3. **정체 기록 규약 부재** — 정체를 "기록했다"는 진술이 있어도 고정된 형식이 없으면 검증할 수 없다(§1 1행이 실제 사례).

## 3. Claude 가 이미 적용한 것 (단독 적용 가능 범위)

- **발신자 태그**: 이 협업의 모든 댓글 첫 줄에 `[Claude]` 를 붙인다. 계정이 같아도 원장에서 신원이 복원된다.
- **차단 호출 시간 제한**: 모든 블로킹 명령에 명시적 타임아웃을 건다. 출력은 `--jq` 등으로 경계를 둔다. 반환되지 않는 호출로 세션이 멈추는 경로를 줄인다.
- **작업 전 흔적**: 오래 걸리는 작업은 시작 **전에** 이슈 댓글이나 인계 파일에 무엇을 시작하는지 남긴다. 중간에 죽어도 진단 가능해진다.

## 4. 양자 조항 — Codex 동의 필요

고정 마커 4종. 첫 줄에 태그와 함께 쓴다.

| 마커 | 뜻 | 필수 동반 정보 |
|---|---|---|
| `HEARTBEAT` | 살아 있고 작업 중 | 지금 붙잡고 있는 대상(커밋·이슈·파일) |
| `BLOCKED` | 멈췄고 스스로 못 푼다 | 무엇을 기다리는지, 재개 조건 |
| `STALL-DETECTED` | 상대가 임계 시간 무응답이라고 판단 | 마지막으로 관측한 상대 마커와 시각 |
| `RESUME` | 재개함 | 무엇을 근거로 재개했는지 |

규칙:

- 리뷰를 요청한 쪽은 **응답 없이 60분**이 지나면 `STALL-DETECTED` 를 남긴다. 남기지 않고 기다리기만 하는 것은 금지한다 — 침묵은 원장에 아무것도 남기지 않는다.
- `STALL-DETECTED` 이후 기다리던 쪽은 **되돌릴 수 있는 작업만** 단독 진행하고, 진행한 내용을 `RESUME` 에 적는다. 배포·파괴적 작업·사람 승인 사안은 해당하지 않는다.
- 동료 메시지는 **사람 승인이 아니다.** 이 규약은 그 경계를 바꾸지 않는다.

### 4.1 판정 규칙 — Codex 제안, Claude 수용

정체를 선언하기 전에 지켜야 할 것들이다. 근거 부족한 선언이 재발하지 않게 하는 핵심 조항이다.

| 조항 | 내용 |
|---|---|
| 전달 ≠ 수신 | **소켓 전달 성공은 수신 ACK 가 아니다.** 메시지가 나갔다는 사실로 상대가 받았다고 판단하지 않는다 |
| 미반환 ≠ 정지 | **pending result 는 hang 이 아니다.** 도구 결과를 관측하지 못한 것과 세션이 멈춘 것은 다른 사건이다 |
| 교차 확인 의무 | `BLOCKED`·`STALL-DETECTED` 선언 **전에** 최신 GitHub 댓글, 원격 HEAD, 상대 세션 진행 흔적을 교차 확인한다. 셋 중 하나라도 전진했으면 상대는 살아 있다 |
| 관측 불명은 unknown | 판정할 수 없으면 `unknown` 으로 남기고 단정하지 않는다. 그 상태에서도 독립 리뷰는 계속한다 |
| 시간 제한 진단 | 진단에 시간 상한을 두고, 복구 후에는 **누적된 리뷰 요청부터 순서대로** 처리한다 |

역할은 그대로다. Claude 가 구현, Codex 가 독립 리뷰·재검증이다.

## 5. 검증 방법

이 규약이 작동하는지는 다음으로 확인한다.

```bash
# 최근 협업 댓글에 발신자 태그가 있는가
gh api "repos/holee9/ra-hermes-multi-agent/issues/150/comments?per_page=20" \
  --jq '.[] | select(.created_at > "2026-09-11") | .body[:12]'
```

태그 없는 댓글이 나오면 그 시점부터 원장의 신원 복원이 다시 깨진 것이다.

## 6. 이 문서가 하지 않는 것

- 세션 간 직접 메시지 채널을 만들지 않는다. Claude 의 통신 상대는 `codex-reviewer` 하나이며, 현재 세션 목록에 없다. 회신 경로는 #150 댓글뿐이다.
- 게이트를 바꾸지 않는다. WP close/reopen 사람 전용, n8n 변경 사전 보고, KB 레포 읽기 전용은 그대로다.
