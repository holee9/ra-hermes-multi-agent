## 미확정 (카탈로그 직접 확인 전 기재 보류)

- ISO 13485:2016/Amd 1:2024 (기후 개정) — 검색에서 카탈로그 페이지 미확인. 존재해도 '13485:2024'라는 새 판번은 아니므로 판번 표기는 2016 유지.
- IEC 62304 Edition 2.0 — 발표 시 이 표와 SOUL 갱신 필요.
